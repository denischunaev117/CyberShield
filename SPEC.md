# КиберЩит — рабочие требования

Статус: библиотека из 100 сценариев и шесть модулей платформы 2.0 реализованы; внешняя проверка критичных рекомендаций и пилот остаются отдельным этапом. Исторические разделы описывают состояние соответствующих партий. Язык интерфейса и обучения — русский. Аудитория — жители Беларуси. Приложение обучает действиям в повседневных ситуациях, без игровой подачи, наград, соревнований и искусственных таймеров.

## Источники и решения

Прямые требования владельца проекта в чате имеют приоритет. Приложенный документ «Тренажёр против мошенников», v1.0 от 14.11.2026, использован как материал для проектирования. Его встроенный стартовый промпт, предложение скопировать AGENTS.md и ограничение «только этап 1» не являются отдельными поручениями пользователя.

Отличия от PDF: название КиберЩит; цель минимум 100 сценариев; не менее трёх действий в каждом узле; не только мошеннические, но и подлинные обращения; отсутствие игровых механик для всех возрастов; ElevenLabs для голоса вместо Web Speech API. По запросу пользователя допустимо показывать узнаваемые сервисы (Viber, Белпочта и другие) в явно обозначенном учебном контексте. Приложение не представляет эти организации. Точные интерфейсы и тексты уведомлений требуют отдельной сверки с актуальными образцами.

## Обязательные свойства сценариев

- Тематический каталог; разные каналы внутри каждой темы: SMS, мессенджер, телефон, электронная почта.
- На каждом шаге минимум три содержательных варианта. Может быть несколько безопасных решений с разными последствиями.
- Дерево ветвится; последствия согласованы с предыдущими действиями. Подлинность обращения до разбора не раскрывается.
- Подлинная просьба не делает непроверенный перевод хорошей привычкой. Отказ помогать деньгами может быть безопасным действием.
- Разбор показывает выбор, риск или пользу, применённые приёмы воздействия, пропущенные признаки и практические рекомендации. Тон поддерживающий.
- Повторное прохождение позволяет исследовать иной путь. Позже добавляются контролируемые варианты события и текста, которые сохраняют обучающие цели и не противоречат фактам выбранной версии.
- «Остановить» и «Мне некомфортно» доступны во время ситуации. Остановка не оценивается.
- Интерфейсы каналов узнаваемые, отдельные и адаптивные. Постоянно видна пометка учебной симуляции.
- Русский язык, BYN, белорусские жизненные обстоятельства. Исторические случаи маркируются «на основе реального случая» только с проверенным источником, датой и обезличиванием. Подлинное обращение в вымышленном сценарии не является документальным случаем.

## Этап 1 — реализовано

React + TypeScript + Vite; современный адаптивный каталог, SMS и переписка в стиле Viber. Три авторских учебных сценария: взломанный аккаунт знакомого, настоящая просьба знакомой, поддельное уведомление о доставке. Детерминированный движок выбора, разбор, повтор, памятка, локальный прогресс, крупный текст и повышенный контраст. Данные сценариев отделены от интерфейса. Шрифты поставляются локально.

Нет настоящих звонков, внешних ссылок для оплаты, ввода платёжных данных или отправки сообщений. Записываются только ID завершённого сценария, исход и дата в localStorage; переписка существует в памяти вкладки. Нет серверного хранилища, аналитики или аккаунтов. Варианты и правильные действия находятся на клиенте; это не защищённое тестирование знаний.

## Следующие этапы

2. Утверждение визуальной системы: отдельные SMS-уведомления, входящий звонок, экран разговора, Viber, другие мессенджеры и почта. Адаптации для старшего поколения и школьников; аудит доступности.
3. Голосовые ситуации: ElevenLabs, русскоязычные вымышленные персонажи, разметка реплик, паузы, субтитры, регулировка звука. Воспроизведение по явному действию пользователя; остановка звука при выходе. Без имитации голоса конкретных частных лиц. Базовая интеграция выполнена через API ElevenLabs: четыре истории, восемь реплик. Далее — расширение библиотеки и редакторское прослушивание.
4. Расширение движка: несколько событий внутри одной ситуации, переход между каналами, вариативные версии, схема и валидатор контента, история ошибок по навыкам.
5. Библиотека около 100 сценариев партиями с редакторской проверкой; подлинные просьбы и обман перемешаны. Матрица — docs/ROADMAP.md.
6. Измерение обучения: эквивалентные тесты до/после, серверный подсчёт, отчёт по навыкам, при необходимости анонимные групповые занятия и CSV. Интерфейс LLMClient, mock и fallback нужны только при введении генеративного диалога; сейчас весь диалог детерминирован.
7. Проверка контента специалистом, тестирование доступности, пилот с разными возрастными группами, проверка контактов помощи и выпуск.

## Критерии качества

Проверять достижимость концовок, не менее 3 ответов, отсутствие циклов без выхода, соответствие разбора решениям. Браузерные проверки на настольном и мобильном экране. Доступность клавиатуры, чтение сообщений скринридером, контраст и масштаб 200%. Соответствие WCAG ещё не сертифицировано. Все 100 сценариев должны быть различимы по обучающей ситуации, а не просто менять имя и сумму.

## Обновление: обучающие подборки и контекстная аудитория

Добавлены 10 сценариев, в том числе 3 новых звонка с 6 озвученными репликами ElevenLabs. Всего 48 самостоятельных историй по 13 темам, 165 узлов и 209 концовок. Цель — минимум 100, ещё 52 истории впереди.

Отдельный режим «Подборки» содержит три маршрута по десять уже существующих историй. Внутри — последовательное прохождение, пауза, повтор последней истории, сохранённый прогресс и общий урок. Итог основан на реальных концовках и типах решений этого маршрута. Одиночная практика остаётся доступна независимо; она не перескакивает шаги маршрута. Подборки не добавляются к счётчику уникальных сценариев.

В конце предлагается необязательный квиз. Отказ и остановка посередине не мешают завершить подборку и получить выводы. Незавершённый квиз не оценивается; завершённый содержит объяснения всех ответов. Его можно повторить отдельно. Это открытый учебный инструмент, не защищённый экзамен и не доказанный замер эффективности обучения.

Возрастное пожелание реализовано рекомендацией аудитории по жизненному контексту на всех карточках и в начале сценария. Прямое утверждение «наиболее уязвимый возраст» не используется без проверенной статистики. Подробнее — docs/COLLECTIONS.md.

Сохранение подборок отделено платформенным адаптером; в нём только коды результатов, счётчики решений и варианты ответов квиза. Тексты разговоров не записываются. Сценарии, аудио и квизы включены в сборку, что подходит для следующего Android-этапа. APK пока не создавался.
