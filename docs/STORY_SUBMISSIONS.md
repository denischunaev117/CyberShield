# Истории пользователей

Раздел «Ваша история» принимает текст, предлагаемый для разработки нового сценария. Получатель, указанный владельцем: `chunaevdenis@gmail.com`. Владелец выбрал отправку через FormSubmit, чтобы посетитель мог отправить заявку внутри приложения без своей почтовой программы.

## Перед использованием

FormSubmit требует однократного подтверждения адреса получателя. После публикации нужно отправить безопасную тестовую историю через раздел сайта и подтвердить письмо FormSubmit в указанной почте. Успешный ответ HTTP от сервиса означает приём в обработку, а не проверенную доставку письма в почтовый ящик. Проверка получения реального письма выполняется владельцем.

Облачная среда разработки блокирует домен FormSubmit сетевым прокси. Прямой запрос к провайдеру и получение настоящего письма из этой среды не подтверждены. Транспорт проверен браузерными тестами с подставными ответами: приём, ошибка сети/сервиса и требование активации. Неподтверждённая отправка не показывается как доставленная.

## Пользовательский путь

1. Прочитать заметное правило: только история, без своих и чужих персональных данных, контактов, реквизитов, документов, кодов, паролей и ссылок на людей. Использовать роли и приблизительные обстоятельства. Не прикладывать скриншоты.
2. Написать 80–6000 символов; необязательно выбрать канал обращения.
3. Перейти к просмотру полного текста. Простые проверки замечают почту, телефоны, длинные номера, ссылки, аккаунты и явно записанные числовые коды. Они не гарантируют обнаружение всех персональных данных, поэтому нужен самостоятельный просмотр.
4. Подтвердить удаление идентифицирующих данных и возможность рассмотрения для учебного сценария.
5. Нажать «Отправить историю». Только после этого выполняется POST. Поля имени и почты отправителя не запрашиваются. Сервис получает текст и технические данные запроса, включая IP-адрес; это раскрыто рядом с кнопкой.

При сетевой ошибке или неподтверждённой активации текст остаётся на экране. Повторные клики во время запроса блокируются, время запроса ограничено. Черновик не записывается в localStorage; закрытие раздела удаляет его из интерфейса. Содержимое не выводится в логи. Нет приложения файлов или автоматической публикации истории.

## Обработка командой

Входящие материалы требуют редакторского просмотра и удаления возможных персональных данных перед любым использованием. История пользователя не подтверждает факты конкретного дела и не должна автоматически становиться документальным сценарием. Публикация не обещается. Этот раздел не является заявлением в милицию, банковским обращением или службой срочной помощи.

Отправка использует внешний HTTPS API FormSubmit; для неё нужен интернет. Готовые учебные сценарии и озвучка продолжают работать без обращения к этому API. При переносе в APK нужно отдельно проверить сетевой доступ и поведение формы офлайн.
