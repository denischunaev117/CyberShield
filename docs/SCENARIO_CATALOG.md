# Реестр 100 идей из PDF

Источник: пользовательский файл `100_scenariev_moshennichestva.pdf`, 14.11.2026. Это редакционный реестр, не 100 готовых сценариев. Сейчас в приложении 100 самостоятельных сценариев. Этот реестр отражает адаптацию идей первого PDF, а не полноту текущего каталога приложения. Партии из белорусского PDF описаны в BELARUS_CATALOG.md; маршруты по готовым историям — в COLLECTIONS.md. Данные источника не считаются проверенной статистикой; ссылки из PDF отдельно не проверялись. Подлинные обращения добавляются как учебные контрпримеры, а не документальные события.

Статус «есть учебная вариация» означает покрытие темы, а не завершение всех её каналов. Цель — минимум 100 самостоятельных проработанных сценариев в приложении.

- Основа из PDF: Во время видеозвонка лицо и голос якобы начальника требуют срочный перевод денег.
- Защита из PDF (до редакторской проверки): Не меняйте платежные процедуры даже при убедительном видеозвонке.
- Адаптация: Белорусский контекст, BYN, проверенные официальные каналы; без реальных реквизитов и действующих платёжных ссылок.
- При разработке: минимум три ответа на каждом шаге; несколько исходов; последствия ранее переданных денег/данных сохраняются в разборе; отдельная проверка всех путей.
