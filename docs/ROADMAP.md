Для каждой истории сохраняются минимум три выбора на шаг, объяснения, несколько концовок и практические выводы. Подборки используют уже учтённые истории: шесть маршрутов по десять ситуаций с общим уроком и необязательным квизом. Озвучены 16 телефонных историй, 32 реплики.

Следующие этапы:

1. Версия 2.0 реализует помощь, локальный анализ сообщений, диагностику, занятия, план навыков и реестры. Возможности — FEATURES_V2.md; состояние публикации — DEPLOYMENT.md.
2. Редакторское прослушивание, экспертная проверка рекомендаций для РБ и пилот с пользователями. Документальные случаи добавлять только с проверенным первичным источником, датой и обезличиванием.
3. Android APK через Capacitor: нативный жизненный цикл, хранение и миграции, TalkBack, офлайн-аудио, реальные устройства, подпись и канал распространения; подробности в ANDROID.md. APK пока не собран.
4. Диагностика до/после и локальная сводка группы реализованы без сервера. Далее — проверка сопоставимости форм и реальный добровольный пилот по PILOT_STUDY.md. Серверные аккаунты/группы потребуют отдельных требований и не входят в этот выпуск.
5. Новые независимые сюжеты и контролируемые вариации на основе обратной связи. Повтор старой истории в подборке не увеличивает каталог.
