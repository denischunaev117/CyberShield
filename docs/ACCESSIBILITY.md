# Читаемость и версия для слабовидящих

Версия 1.1 увеличивает обычный интерфейс примерно до прежнего масштаба 125%: размеры текста, отступов, кнопок, карточек и окон выражены в `rem`, корневой размер — 125% от браузерного. Основные подписи не используют прежние 8–10 px; текст карточек и подписи каталога в обычном режиме имеют размер от 15 CSS px; компактная мобильная навигация использует отдельные размеры. Декоративная миниатюра телефона не является основным учебным текстом.

Есть независимый переключатель светлой и тёмной темы. В настройках вместо двух прежних флажков — один «Версия для слабовидящих». Выбор темы и режима сохраняется в `cybershield-preferences-v1`. Если запись запрещена, интерфейс сообщает об этом и сохраняет настройки в текущей вкладке.

## На что опирается режим

WCAG не задаёт одну обязательную цветовую схему для всех слабовидящих. Контраст считают по относительной яркости, а удобный фон зависит от пользователя. Поэтому контрастная версия работает в обеих темах: тёмный текст `#111` на белом `#fff` либо белый на `#111`, контраст примерно 18.9:1. Выбранные кнопки используют инверсию этих цветов. Основной текст в режиме имеет размер от 24 CSS px, межстрочный интервал 1.7, свободные интервалы и заметные границы управления. Декоративные иллюстрации скрываются, а названия каналов и учебные материалы остаются.

Основные ориентиры:

- WCAG 1.4.3: не менее 4.5:1 для обычного текста и 3:1 для крупного.
- WCAG 1.4.6: усиленный контраст — 7:1 для обычного текста, 4.5:1 для крупного. Контрастная версия использует ещё более высокий контраст чёрного и белого.
- WCAG 1.4.4 и 1.4.10: увеличение текста до 200% и перестроение страницы при ширине 320 CSS px без потери содержания или функций. Масштаб браузера не блокируется.
- WCAG 1.4.12: пользователь должен иметь возможность увеличить интервалы между строками, словами, буквами и абзацами без потери содержания. Значения этого критерия — проверка переносимости пользовательских настроек, а не требование навязать всем одинаковые интервалы.
- WCAG 2.5.8: минимум 24×24 CSS px либо достаточные интервалы; расширенный критерий 2.5.5 использует 44×44. Основные кнопки здесь имеют высоту от 48 CSS px, в контрастной версии — от 52.8 px. Флажки находятся внутри крупных кликабельных подписей.

Режим также сохраняет управление клавиатурой, видимый фокус, подписи полей и озвучиваемые состояния. Ошибка обозначается словами и значком, а не только цветом. При `prefers-reduced-motion` отключаются переходы и плавная прокрутка.

## Проверенные источники

Официальные пояснения W3C доступны на сайте стандарта и в репозитории авторов. Основной домен W3C был недоступен из облачной среды из-за сетевой политики; прочитаны соответствующие официальные файлы GitHub:

- [Contrast Minimum](https://github.com/w3c/wcag/blob/main/understanding/20/contrast-minimum.html)
- [Contrast Enhanced](https://github.com/w3c/wcag/blob/main/understanding/20/contrast-enhanced.html)
- [Resize Text](https://github.com/w3c/wcag/blob/main/understanding/20/resize-text.html)
- [Reflow](https://github.com/w3c/wcag/blob/main/understanding/21/reflow.html)
- [Text Spacing](https://github.com/w3c/wcag/blob/main/understanding/21/text-spacing.html)
- [Target Size Minimum](https://github.com/w3c/wcag/blob/main/understanding/22/target-size-minimum.html)

Автоматические проверки Chromium/axe и проверки размеров не являются сертификацией соответствия всем требованиям WCAG. Отдельно нужны пользовательская проверка со скринридером и реальное Android-устройство при подготовке APK.
