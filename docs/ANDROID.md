# CyberShield для Android — APK 2.4.0

Собран подписанный release APK `by.cybershield.app`, versionName `2.4.0`,
versionCode `20400`. Файл и исходники находятся в отдельной папке
`/workspace/CyberShield-Android/`. Это локально упакованное приложение Capacitor,
не загрузчик сайта с GitHub Pages. Веб-сайт этой сборкой не публиковался.

## Файлы

- `downloads/CyberShield-2.4.0.apk` — устанавливаемый release APK.
- `downloads/CyberShield-2.4.0.apk.sha256` — контрольная сумма.
- `source/` — исходники приложения и архив для переноса.
- `reports/` — подпись, содержимое APK, проверки и Android Lint.
- `private-signing/` — закрытый ключ подписи и пароль, доступ только владельцу
  облачной папки. Не включены в APK или архив исходников. Сохраните отдельную
  резервную копию: обновления устанавливаются с той же подписью.

## Установка и возможности

Нужны Android 8 или новее и Android System WebView/Chrome версии 123 или новее.
При устаревшем WebView есть локальная страница с объяснением на RU/BE/EN.
Скачайте APK на телефон, откройте файл и подтвердите установку системным
установщиком Android. Разрешение установки из выбранного источника задаётся
самой ОС для браузера или приложения «Файлы».

В APK включены все 100 сценариев, три языка, 96 MP3, QR-декодер, движок OCR
и три языковые модели. Для этих ресурсов загрузка с GitHub/CDN не требуется.
Онлайн-проверка адресов и добровольная отправка истории требуют интернета.
Проверка Google обращается только к фиксированному Worker; ключ Google в APK
не включён. Содержимое проверяемого сайта не открывается и цепочки переходов
не раскрываются, как и в веб-версии 2.3.

Прогресс и настройки сохраняются в приватных данных WebView приложения.
Автоматический облачный backup/перенос отключён. Обновление тем же ключом
сохраняет данные; удаление приложения или очистка его данных удаляет их.
Данные из браузера автоматически в отдельное Android-приложение не переносятся.

Кнопка «Назад» сначала закрывает меню/настройки, приостанавливает ситуацию,
затем возвращает к практике; из корня закрывает приложение. При сворачивании
останавливаются аудио, камера, OCR и незавершённая онлайн-проверка.
Сохранение JSON/CSV использует системное «Сохранить как» через Storage Access
Framework. Печать/сохранение PDF использует PrintManager. Отмена этих окон
не объявляется успешным сохранением или печатью.

Разрешения: интернет и камера. Камера запрашивается по кнопке и не обязательна
для установки. Доступ к SMS, контактам, микрофону и общему хранилищу не запрашивается.
Релиз не допускает отладку WebView и незашифрованный HTTP-трафик приложения.

## Сборка из исходников

Зафиксированы Capacitor core/android/cli 8.6.2 и App 8.1.2, Gradle 8.14.3,
Android Gradle Plugin 8.13.0, JDK 21. Android SDK platform 36,
build-tools 36.0.0; совместимый SDK Manager 19.0. Gradle-дистрибутив проверяется
по опубликованному SHA-256, NPM — по lockfile.

```sh
npm ci --cache /tmp/cybershield-npm-cache
npm run check:locales
npm run lint
npm test
npm run android:release
```

Укажите `JAVA_HOME`, `ANDROID_HOME` для своей машины. Для подписи скрипт читает
`CYBERSHIELD_ANDROID_SIGNING_DIR` (папка с `cybershield-release.p12` и
`credentials.json`), иначе отдельную `../CyberShield-Android/private-signing`.
Поля JSON — `storePassword`, `keyPassword`, alias `cybershield`.
Значения не передаются в командной строке, исходниках или клиентской сборке.
Без ключа скрипт не выдаёт неподписанный файл за release APK.

`android:release` собирает production web assets, выполняет Capacitor sync,
Gradle assembleRelease/lintRelease и apksigner verify, копирует APK, SHA-256
и отчёты в отдельную папку. Локальные SDK, Gradle cache, .env и подпись
в исходники приложения не входят.

## Особенность OCR в APK

AAPT распаковывает assets с расширением `.gz` и убирает суффикс. Поэтому
Android использует `gzip: false`, а браузер — прежний `gzip: true`.
Байты всех трёх `.traineddata` внутри APK сверены с распакованными оригиналами;
исходные `.traineddata.gz`, лицензии, аудиофайлы и их fingerprints не менялись.

## Что проверено

- Android release сборка и Android Lint успешны.
- Подпись APK проверена apksigner, пакет/minSdk/targetSdk/permissions — aapt.
- Все 96 MP3 в APK совпадают с исходными SHA-256, три OCR-модели включены.
- JavaScript/CSS внутри APK совпадают с финальной production-сборкой.
- 766 модульных и 50 целевых браузерных проверок прошли, в том числе
  нативные события Back/Pause, аудио, камера, QR, настоящий OCR и онлайн-проверка.
- Полнота всех 6058 фраз и 21 шаблона EN/BE, TypeScript и lint проверены.

Физический Android-телефон в среде не подключён. Созданный эмулятор Android 16
без KVM не завершил загрузку: система Android перезапускается до установки APK.
Попытка установки вернула «device is still booting». Поэтому установка,
TalkBack, камера, системные Save As/печать и работа в авиарежиме на реальном
телефоне ещё требуют проверки; браузерные тесты не выданы за Android-проверки.

## Исправление системных панелей в 2.4

MainActivity самостоятельно резервирует нативные отступы status/navigation bars,
выреза экрана и клавиатуры. WebView получает нулевые системные insets после
размещения внутри безопасного прямоугольника; зависимость от CSS env и изменений
WebView 140+ устранена. Встроенный обработчик SystemBars insets отключён, чтобы
не было двух конкурирующих схем. Цвет полей и контраст иконок обновляются вместе
со светлой/тёмной темой; поворот экрана восстанавливает выбранный цвет.
Физическая проверка нового APK на телефоне остаётся необходимой.
