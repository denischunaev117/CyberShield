Опубликовано: https://denischunaev117.github.io/CyberShield/

Версия **2.1.0**, коммит `dbd1c01`, опубликована 15 ноября 2026.
[Успешный workflow и проверка публичных ресурсов](https://github.com/denischunaev117/CyberShield/actions/runs/43702276171).

GitHub Actions повторил lint, все 568 модульных проверок, TypeScript/production-сборку и все 346 браузерных тестов. Выпуск опубликован через Pages. Шаг **Verify public page, assets and every audio clip** успешно проверил публичные HTML, JS/CSS и все 32 MP3 с SHA-256. Полный workflow занял 7 минут 47 секунд.

Подтверждение публичных ресурсов получено из GitHub Actions. Ранее прямые запросы из облачной среды блокировал сетевой прокси; локальная сборка сама по себе не подтверждает доступность публикации.

Сайт — статическая production-сборка из `dist/`. Ключ ElevenLabs ей не нужен: MP3 уже созданы. В сборку нельзя включать `.env`, ключи или окружение генератора. Исходный Files.zip в публикацию не включён: используются подготовленные пояснения, правила и метаданные происхождения.

## GitHub Pages

Подготовлен `.github/workflows/deploy-pages.yml`. При push в `main` или ручном запуске он устанавливает зависимости, выполняет lint, тесты данных, сборку и браузерные тесты, затем публикует проверенный `dist/` через официальный Pages artifact.

Один раз в настройках репозитория `denischunaev117/CyberShield` нужно выбрать **Settings → Pages → Build and deployment → Source: GitHub Actions**. Затем запустить workflow **Check and deploy CyberShield**. Существующие правила защиты environment `github-pages` продолжают действовать. Видимость репозитория workflow не меняет.

`actions/configure-pages` не пытается включать Pages через обычный `GITHUB_TOKEN`: согласно описанию action, автоматическое включение требует отдельного токена с дополнительными правами. Такой секрет в проект не добавлен. Если Pages уже включён для Actions, дополнительных токенов не требуется.

Публичный адрес берётся из результата шага `actions/deploy-pages`, после чего нужно открыть его извне, проверить главную страницу, подборку и воспроизведение звонка. После deployment `scripts/verify-public-site.mjs` загружает публичную HTML-страницу, её JS/CSS и все MP3 из манифеста со сверкой SHA-256; ошибки HTTP, отсутствующие ресурсы и изменённое аудио завершают workflow с ошибкой. Для распространения Pages предусмотрены ограниченные повторы проверки.

Файл workflow, успешная локальная сборка и предполагаемое имя домена сами по себе не подтверждают публикацию.

## Проверка путей

Vite использует относительную базу `./`. `src/platform/assets.ts` разрешает путь MP3 относительно текущей страницы. Playwright проверяет собранный сайт в `/CyberShield/`: загрузку всех 100 карточек, озвучку, остановку и перезагрузку, lazy-модули версии 2.0 и прямую ссылку `?lesson=ID`. Обычный запуск из корня также покрыт браузерными тестами.

## Ограничения текущей облачной среды

При подготовке публикации GitHub API вернул `Tunnel connection failed: 403 Forbidden` от сетевого прокси. Это отказ сети, а не доказательство недействительного токена. Активная конфигурация среды разрешала ElevenLabs и preset package_managers; `api.github.com` и `denischunaev117.github.io` отсутствовали в применённом списке.

GitHub Pages включён владельцем для GitHub Actions. Повторная публикация и проверка публичных ресурсов успешно завершены; актуальная ссылка указана выше.

В черновике конфигурации среды сохранено добавление этих двух доменов с сохранением прежних разрешений. Черновик требует применения через интерфейс среды; изменение черновика не включает доступ в уже работающей конфигурации. После применения нужно повторно проверить доступ к GitHub API и публичному сайту. Не отключайте проверку TLS и не обходите сетевую политику.

## Другой статический хостинг

Можно загрузить содержимое `dist/` на выбранный владельцем статический хостинг с HTTPS. Сайт должен открываться через веб-сервер, а не двойным щелчком по `index.html`. Разрешения настоящих SMS, контактов и микрофона ему не требуются. Перенос на другой origin не переносит localStorage: прогресс останется в прежнем браузерном origin.
