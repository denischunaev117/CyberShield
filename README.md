# КиберЩит

**[Открыть приложение](https://denischunaev117.github.io/CyberShield/)** · [Проверки и публикация](https://github.com/denischunaev117/CyberShield/actions/workflows/deploy-pages.yml)

Обучающее приложение для жителей Беларуси. Доступны русский, английский и белорусский языки: **100 самостоятельных ветвящихся сценариев по 14 темам**, 353 шага выбора и 415 концовок. В каждой ситуации не менее трёх ответов на шаг; безопасных действий может быть несколько. В 19 историях обращения настоящие, в остальных моделируется обман. Все истории вымышленные учебные адаптации.

**Выпуск 2.2.0:** полный перевод RU/EN/BE и локальная проверка ссылки, QR-кода и скриншота. Подробности — [LOCALIZATION.md](docs/LOCALIZATION.md), [LINK_QR.md](docs/LINK_QR.md). Фактический результат публикации подтверждается успешным workflow для main, включая проверку публичных ресурсов.

Каналы: SMS, Viber, Telegram, WhatsApp, Instagram, электронная почта, учебные веб-страницы и 16 телефонных историй с озвучкой ElevenLabs. Есть разбор каждого решения, типичные ошибки, практические выводы, повторное прохождение, остановка без оценки, памятка, светлая и тёмная темы, единая версия для слабовидящих.

Отдельный раздел «Подборки» содержит шесть маршрутов по десять существующих историй. В конце — общий урок, итоги своего пути и необязательный квиз из трёх вопросов. Можно отказаться, остановить квиз или вернуться к нему позднее. Любая история доступна и отдельно.

## Запуск и проверка

Требуется Node.js 22.12+ и npm (проверено на Node 24).

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

```sh
npm run check:locales
npm run lint
npm test
npm run test:e2e -- --workers=3
```

`test:e2e` сначала создаёт production-сборку, затем запускает Playwright. Используется системный Chromium `/usr/bin/chromium`; путь можно изменить через `CHROMIUM_PATH`. Тесты автоматически запускают Vite и preview на портах 5173 и 4173. Проверяются графы и все ветви, последствия решений, MP3 и соответствие тексту, подборки, самостоятельное браузерное прохождение всех 100 историй, озвучка, повтор, хранилище, доступность и мобильная вёрстка. Отдельный тест проверяет production-сборку в подкаталоге `/CyberShield/`, включая воспроизведение аудио.

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Шрифты и готовая озвучка включены локально. Для прохождения не нужны ключи, сервер или сторонние API. Результаты хранятся в localStorage текущего браузера, без текстов переписки. Очистка данных сайта удаляет прогресс; тема и версия для слабовидящих сохраняются в этом браузере. При запрете хранения интерфейс сообщает об этом.

## Обновление 2.0

Исправлены перенос логотипа и границы кнопок в режиме для слабовидящих; навигация расширена с сохранением крупных элементов. Добавлены все шесть модулей из ТЗ:

- **Мне нужна помощь** — пошаговый выбор ситуации и порядок действий без ввода личных данных.
- **Проверить сообщение** — 37 объяснимых локальных групп признаков, без отправки текста и открытия ссылок.
- **Диагностика** — 24 вопроса в двух формах, добровольная проверка до/после, десять навыков, отдельная позднейшая проверка.
- **Занятия** — три плана на 25–28 минут, локальный QR, печатные материалы и добровольные обезличенные сводки группы.
- **Мой план** — пять историй по навыкам, объяснение основания, изменение и повтор без двойного зачёта.
- **Источники и методика** — реестры происхождения и независимой проверки материалов.

Новые модули не требуют сервера, ключа ИИ или регистрации. Участник сам решает, скачивать ли сводку; ведущий импортирует её локально. Диагностика, план и занятия хранятся отдельно от прежнего прогресса. Проверка сообщения работает только в памяти открытого раздела.

Подробности: [возможности 2.0](docs/FEATURES_V2.md), [данные и приватность](docs/PRIVACY_V2.md), [проверка контента](docs/CONTENT_REVIEW.md), [план пилота](docs/PILOT_STUDY.md).

Независимая экспертиза и пилот ещё не проведены. Использованы переданные копии материалов девяти организаций; их актуальность на живых сайтах независимо не проверена. Шесть прочитанных пояснений W3C относятся к доступности, а не к банковским рекомендациям. Диагностика — учебная оценка, не защищённый экзамен и не доказательство эффективности.

## Сохранённые возможности 1.1

Разбор всех 100 сценариев явно показывает серьёзную ошибку, последствия и каждый опасный выбор с номером шага, объяснением и безопасными вариантами. Если человек остановился после потери, разбор не объявляет последствия устранёнными. Срочные рекомендации выбраны по контексту каждой истории: деньги, доступ, устройство, документы, договор, здоровье или расчёт. Подлинные обращения и безопасная остановка до ущерба различаются с проваленным сценарием.

Базовый интерфейс увеличен примерно на 25%, мелкие содержательные подписи — до 15 CSS px и выше. Тема переключается в шапке, а в настройках есть единая «Версия для слабовидящих», совместимая с обеими темами. Подробнее и источники WCAG — [docs/ACCESSIBILITY.md](docs/ACCESSIBILITY.md).

Раздел «Ваша история» предлагает предварительный просмотр и подтверждение удаления персональных данных. Отправка на адрес владельца выполняется через выбранный им FormSubmit, только по явному действию посетителя. Владелец подтвердил активацию адреса и фактическое получение заявок. Автотесты проверяют транспорт с подставными ответами и не отправляют реальные письма. Подробности — [docs/STORY_SUBMISSIONS.md](docs/STORY_SUBMISSIONS.md).

## Голосовые истории

В `public/audio/` находятся 32 русские MP3-реплики для 16 историй, созданные через ElevenLabs `eleven_multilingual_v2`. В `public/audio/en/` и `public/audio/be/` сохранены ещё по 32 готовые реплики (`eleven_v4_turbo`): всего 96 файлов, повторная генерация для локализации не требуется. Используются стандартные голоса вымышленных персонажей; голоса реальных знакомых не клонируются. Воспроизведение запускает пользователь, текст всегда доступен. При остановке, смене шага и выходе звук прекращается. Независимая проверка и последующие события показаны текстом повествователя. При ошибке аудио можно продолжить по тексту.

Повторная генерация — отдельная платная операция:

```sh
python3 scripts/generate-voices.py
```

`ELEVENLABS_API_KEY` читается только из окружения Python. Не добавляйте префикс `VITE_` и не включайте ключ в исходники, сайт или APK. Генератор сверяет текст, голос, модель и SHA-256, пропускает готовые совпадающие файлы, ограничивает партию 8000 символами и не повторяет платные запросы автоматически. Обычная сборка и прохождение API не вызывают. Не изменяйте fingerprint вручную для обхода проверки актуальности.

## Последние 28 историй

`batch-eight.ts` и `batch-nine.ts` завершают библиотеку: секретная операция, настоящая помощь родственнику после дорожного происшествия, компенсация, продажа квартиры «для защиты», настоящая скидка, возврат после заказа, магазин-клон, криптообменник, настоящий налог, банковский опрос и бот, поддельный кредит маркетплейса, QR стажировки, взнос за работу, билеты на свидание, настоящий заказ цветов, криптотреугольник, «проверка законности» криптовалюты, денежный курьер, давление в личной переписке, игровой облачный аккаунт, импорт и продажа автомобиля, аренда в Telegram, приз блогера, наличные от курьера, фальшивая поддержка партнёров и давление скидкой для пенсионеров.

## Границы текущей версии

Контент и источники PDF не прошли независимую документальную проверку; истории не объявляются реальными делами. Интерфейсы мессенджеров узнаваемые, но не точные копии текущих версий. Сервер и аккаунты не реализованы. Диагностика и группы работают локально, без централизованной базы участников. Автоматические проверки не заменяют прослушивание носителями языка, пилот с людьми и экспертную проверку учебных рекомендаций.

Мобильная вёрстка проверяется в Chromium. APK ещё не собран; Android WebView, TalkBack, нативное хранение и Safari требуют отдельных проверок.
